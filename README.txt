ANIIMO CATCH & VARIANT TRACKER — PORTABLE PACKAGE

START HERE
1. Extract this ZIP folder anywhere on your Windows PC.
2. Double-click "Launch Aniimo Tracker.bat".
   It opens the tracker in an app-style window using Microsoft Edge or Google Chrome.
3. Check off Aniimo forms and variants. No internet connection or installation is required.

SHARING
Send this ZIP file to friends. Each person should extract their own copy and launch it.
Their collection progress is stored locally in that browser profile and is not automatically shared.
Use the tracker's Download backup (.json) and Import backup controls to transfer progress.

CONTENTS
- html/Aniimo Tracker.html: the offline tracker page.
- ui/js/aniimo-tracker.js and css/aniimo-tracker.css: its local script and stylesheet.
Keep these folders together when copying the portable tracker.
- Launch Aniimo Tracker.bat: opens it in an app-style window on Windows with Edge or Chrome.

NOTE
This is a portable offline app package, not a compiled .EXE. The launcher requires Edge or Chrome
installed on Windows. You can also open the HTML file directly in any modern browser.
