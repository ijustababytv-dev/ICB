🎬 One Meld layer for everything

Meld link
Add this link to Meld once as a full-screen browser layer. It shows every effect that's switched on. To change between leaves, ghosts or anything else, flip the switches below or press ▶ Show only this one on the effect you want. (Each effect's own link still works too, if you'd rather have separate layers. Don't use both for the same effect or it shows twice.)

🖼️ Picture library

Every picture you've added, from every effect, in one place. Click an effect's name under a picture to send that picture into it (click again to take it out) — no need to upload the same picture twice. Highlighted pictures are in use somewhere.
Drop pictures here to add them to the library (or click to pick files)
New library pictures are saved in ICB\assets\decor\misc\. Pictures you drop on an effect card below still go into that effect's own folder, and show up here too.

Presets

A preset remembers every effect's on/off, amount, speed, size, see-through and which art is ticked. Saving with an existing name updates it.

Add a new effect

Every effect gets its own art folder and its own Meld link, and shows up on the "everything" layer. Pick how it moves: falls down (leaves, snow, candy corn), floats up (ghosts, bubbles, hearts) or flies across (bats, butterflies, clouds). You can change the motion any time.
