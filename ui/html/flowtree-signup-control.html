🎭 Roles (yours to set up)

Each role gets its own chat command. Example: role Fish Prep with command fish → chat types !fish Moon Pie. Spots: 0 = unlimited; past the spots people go on a waitlist and move up when someone leaves. No roles = chat just types ! + their name.
