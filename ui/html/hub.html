🛠 Troubleshooting guide

The giveaway dashboard says "Meld listener is NOT running"
  1. Look at the Meld chat listener line in Connection check at the top of this page. If it's red, the listener layer isn't loaded in Meld.
  2. In Meld, the layer http://127.0.0.1:8790/giveaway-listener.html must be in the scene you're on, with its eye turned on. The address must be exactly that.
  3. Right-click the layer in Meld and choose reload. Within 10 seconds the line should turn green.
  4. If ICB itself was restarted, the listener reconnects by itself within a few seconds. If it doesn't, reload the layer.
  5. Layer is on, address is right, reloading does nothing, and it's still red? Meld has stopped running its local layers (this happened 2026-09-30 — walkers and leaves froze too). Fully close Meld (check the tray by the clock) and open it again. That fixed it. If you're live and can't restart, ask Claude about running the listener as a Meld element instead.
  6. Keep one listener per scene you stream in — never two in the same scene, or subs/gifts/bits can count twice.
Meld says "disconnected from server"
  1. That's Meld's own connection, not ICB. No chat can reach ICB until Meld reconnects.
  2. Close Meld completely (check the tray by the clock) and open it again. Make sure you're still signed in to Twitch in Meld.
  3. Check your internet. If Meld still won't connect, check Meld's Discord or X in case their servers are down.
  4. Once Meld is connected, press ↻ Reload the listener here (or reload the layer in Meld).
Listener is green but chat doesn't show up (no unicorns, no chat entries)
  1. Type a test message in your Twitch chat, then watch the Chat reaching ICB line. It should say "last chat a few seconds ago".
  2. If it doesn't change, Meld isn't getting your Twitch chat. Check the Twitch connection in Meld's settings and sign in again if needed, then reload the listener.
  3. If chat arrives but no Chat Unicorn appears: only subscribers get one automatically. Tick the person (or yourself) on the Chat Unicorns dashboard.
An overlay isn't showing on stream
  1. Find it under Overlays in Meld. If it says "not open", Meld hasn't loaded that layer. Add it, turn its eye on, or reload it.
  2. If it says "open" but you can't see it, it's loaded but hidden. It may be under another layer, sized wrong (should be 1920×1080 for full-screen overlays), or turned off on its own dashboard.
  3. Most dashboards have a 🧪 Test button. Press it while you watch Meld.
Nothing works / every line is red
  1. ICB is probably not running. Open the ICB folder (Documents\GitHub\ICB) and double-click restart-icb-clean.bat.
  2. Wait until this page says connected at the top right. Then reload the layers in Meld (the listener first).
Palia trackers aren't counting
  1. Palia Assistant must be running while you play. The trackers read its log file.
  2. The Palia log reader line shows "live" while the log keeps changing. It goes quiet a few minutes after you stop playing, which is normal.
After Claude sends an update
  1. If server.js changed: run restart-icb-clean.bat.
  2. If only a page changed: reload that layer in Meld, or refresh the dashboard tab.

Opening pages when ICB starts

Tick Open when ICB starts on any tile. When you run start-icb-clean.bat or restart-icb-clean.bat, Chrome opens ICB Home plus every ticked page, each in its own tab. Clicking Open on a tile again reuses the tab it opened before, instead of stacking up duplicates.
